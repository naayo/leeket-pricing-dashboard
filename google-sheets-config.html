🔗 Configuration Google Sheets pour Leeket Dashboard

⚠️ Important : Cette configuration nécessite de rendre votre Google Sheet publique en lecture seule ou d'utiliser une clé API Google.

Étape 1 : Préparer votre Google Sheet

  1. Ouvrez votre Google Sheet contenant les données de prix
  2. Assurez-vous que votre feuille contient ces colonnes :
    • Produit ou Product - Nom du produit
    • Prix ou Prix Marché - Prix du marché
    • Catégorie ou Category - Catégorie du produit (optionnel)
    • Coût ou Cost - Coût du produit (optionnel)

Étape 2 : Rendre le Google Sheet accessible

Option A : Méthode Simple (Recommandée)

  1. Dans Google Sheets, cliquez sur Fichier > Partager > Publier sur le Web
  2. Choisissez la feuille à publier
  3. Sélectionnez le format CSV
  4. Cliquez sur Publier
  5. Copiez le lien généré

Option B : Partage en lecture seule

  1. Cliquez sur le bouton Partager en haut à droite
  2. Changez les permissions à "Tous les utilisateurs disposant du lien peuvent consulter"
  3. Copiez le lien de partage

Étape 3 : Obtenir l'ID de votre Google Sheet

L'ID se trouve dans l'URL de votre Google Sheet :

https://docs.google.com/spreadsheets/d/VOTRE_ID_ICI/edit

Exemple d'ID : 1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgvE2upms
